# Jarvis v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gör forken `berrabang/jarvis` till Antons röststyrda Jarvis v1: helt lokal taligenkänning, vakt i tre nivåer med muntlig bekräftelse, lokalt minne, nedladdning/shorts/sortering i en egen Jarvis-mapp – byggd på Windows.

**Architecture:** Forkens HUD (React/Three.js) och Node-brygga (Claude Agent SDK) behålls. Tre små Python-tjänster läggs till bredvid: `services/stt` (faster-whisper över HTTP), `services/memory` och `services/media` (båda MCP-servrar över stdio). Bryggan får en ny vakt (`bridge/guard.mjs` + `policy.json`) som avgör varje verktygsanrop och frågar via HUD:n när det behövs.

**Tech Stack:** Node.js 24 LTS (ESM `.mjs`, `node --test`), React 19 + Vite + TypeScript, Python ≥ 3.11 med `uv`, `faster-whisper`, MCP Python SDK (`mcp`), ffmpeg/ffprobe, Claude Agent SDK.

**Spec:** `docs/superpowers/specs/2026-11-25-jarvis-design.md` – läs den före varje uppgift; planen argumenterar utifrån den.

## Global Constraints

- Plattform: Windows 10/11 x64. Alla kommandon är PowerShell, körda från repots rot i VS Code-terminalen.
- Node.js **24 LTS** (testerna importerar `.ts`-filer via Nodes inbyggda typstrippning, som kräver ≥ 22.18).
- Python ≥ 3.11 via `uv`. Varje tjänst körs med `uv run --directory services/<namn> …`.
- Alla lokala tjänster lyssnar bara på `127.0.0.1`. Portar: HUD 5173, brygga 8787, taltjänst 8790.
- Ingen molnreserv för tal: webbläsarens SpeechRecognition startas aldrig om inte `VITE_ALLOW_BROWSER_STT=1`.
- Vakten stänger vid fel (`deny`). Okänt verktyg ⇒ `ask`. Bekräftelse: 20 s, en omfråga, sedan nej.
- Jarvis-mapp: `%USERPROFILE%\Jarvis\` med exakt undermapparna i spec §4.7. Dold data: `%USERPROFILE%\.jarvis\`.
- Namnregel: `ÅÅÅÅ-MM-DD_kort-beskrivning.ext`, gemener, bindestreck, å/ä→a, ö→o, krock ⇒ `-2`, `-3` …
- Nycklar och `.env` committas aldrig.
- Forkens befintliga tester (`npm test`) ska passera efter varje uppgift.
- Kodkommentarer på engelska (som i forken). Text till Anton på svenska. Jarvis talar engelska i v1.
- Varje commit-meddelande slutar med raden `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

`services/stt/jarvis_stt/engine.py`:

```python
"""faster-whisper behind a tiny interface the HTTP layer can fake in tests."""
from __future__ import annotations

import io
import time
from typing import Protocol


class Transcriber(Protocol):
    def transcribe(self, data: bytes, with_segments: bool = False) -> dict: ...


class WhisperTranscriber:
    def __init__(self, model_size: str = "small", device: str = "auto", compute_type: str = "int8"):
        # Imported here so the HTTP tests never load the model or its runtime.
        from faster_whisper import WhisperModel

        self.model_size = model_size
        self._model = WhisperModel(model_size, device=device, compute_type=compute_type)

    def transcribe(self, data: bytes, with_segments: bool = False) -> dict:
        started = time.perf_counter()
        segments, info = self._model.transcribe(io.BytesIO(data), beam_size=1, vad_filter=False)
        parts = [
            {"start": round(s.start, 2), "end": round(s.end, 2), "text": s.text.strip()}
            for s in segments
        ]
        result = {
            "text": " ".join(p["text"] for p in parts).strip(),
            "language": info.language,
            "duration_ms": int((time.perf_counter() - started) * 1000),
        }
        if with_segments:
            result["segments"] = parts
        return result
```

`services/stt/jarvis_stt/app.py`:

```python
"""HTTP front for the transcriber. Standard library only, loopback only."""
from __future__ import annotations

import json
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlparse

MAX_BYTES = 25 * 1024 * 1024
MIN_BYTES = 1200  # shorter than this is a click, not speech
TYPES = {
    "audio/webm", "audio/ogg", "audio/wav", "audio/x-wav", "audio/wave",
    "audio/mp4", "audio/mpeg", "video/mp4", "video/webm",
}
LOOPBACK = {"127.0.0.1", "::1", "localhost"}


def make_handler(transcriber, model_name: str):
    class Handler(BaseHTTPRequestHandler):
        def log_message(self, fmt, *args):  # one line per request is noise here
            pass

        def _json(self, status: int, body: dict) -> None:
            raw = json.dumps(body).encode()
            self.send_response(status)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(raw)))
            self.end_headers()
            self.wfile.write(raw)

        def do_GET(self):
            if urlparse(self.path).path == "/health":
                return self._json(200, {"ok": True, "model": model_name})
            return self._json(404, {"error": "not found"})

        def do_POST(self):
            url = urlparse(self.path)
            if url.path != "/transcribe":
                return self._json(404, {"error": "not found"})
            ctype = (self.headers.get("Content-Type") or "").split(";")[0].strip().lower()
            if ctype not in TYPES:
                return self._json(400, {"error": f"unsupported content type: {ctype or 'none'}"})
            length = int(self.headers.get("Content-Length") or 0)
            if length > MAX_BYTES:
                return self._json(413, {"error": "audio too large"})
            data = self.rfile.read(length) if length else b""
            with_segments = parse_qs(url.query).get("segments") == ["1"]
            if len(data) < MIN_BYTES:
                body = {"text": "", "language": None, "duration_ms": 0}
                if with_segments:
                    body["segments"] = []
                return self._json(200, body)
            try:
                return self._json(200, transcriber.transcribe(data, with_segments=with_segments))
            except Exception as err:  # the audio decoder raises many types
                return self._json(500, {"error": str(err)})

    return Handler


def make_server(transcriber, model_name: str, host: str = "127.0.0.1", port: int = 8790):
    if host not in LOOPBACK:
        raise ValueError("the speech service only listens on this machine")
    return ThreadingHTTPServer((host, port), make_handler(transcriber, model_name))
```

```js
import assert from 'node:assert/strict'
import { createServer } from 'node:http'
import { localSttHealthy, sttMode, sttUrl, transcribeLocal } from '../bridge/stt.mjs'

function fakeService(handler) {
  return new Promise((resolve) => {
    const server = createServer(handler)
    server.listen(0, '127.0.0.1', () =>
      resolve({ server, url: `http://127.0.0.1:${server.address().port}` }),
    )

test('local is the default speech engine', () => {
  assert.equal(sttMode({}), 'local')
  assert.equal(sttMode({ JARVIS_STT: 'elevenlabs' }), 'elevenlabs')
  assert.equal(sttUrl({}), 'http://127.0.0.1:8790')
  assert.equal(sttUrl({ JARVIS_STT_URL: 'http://127.0.0.1:9000/' }), 'http://127.0.0.1:9000')

test('transcribeLocal forwards bytes and type, and passes the answer through', async () => {
  let seen
  const { server, url } = await fakeService((req, res) => {
    const chunks = []
    req.on('data', (c) => chunks.push(c))
    req.on('end', () => {
      seen = { path: req.url, type: req.headers['content-type'], size: Buffer.concat(chunks).length }
      res.writeHead(200, { 'content-type': 'application/json' })
      res.end(JSON.stringify({ text: 'hello jarvis', language: 'en', duration_ms: 3 }))
    })
  })
  try {
    const out = await transcribeLocal(Buffer.alloc(5000, 1), 'audio/ogg', url)
    assert.deepEqual(seen, { path: '/transcribe', type: 'audio/ogg', size: 5000 })
    assert.equal(out.status, 200)
    assert.equal(out.body.text, 'hello jarvis')
  } finally {
    server.close()
  }
})

test('an unreachable service is a 503, never a throw', async () => {
  const out = await transcribeLocal(Buffer.alloc(10), 'audio/webm', 'http://127.0.0.1:9')
  assert.equal(out.status, 503)
```

```js
/**
 * Where speech goes to become text.
 *
 *   local      — services/stt (faster-whisper on this machine). The default in
 *                this fork: audio never leaves the PC.
 *   elevenlabs — the upstream path, ElevenLabs Scribe, only when chosen.
 */
export function sttMode(env = process.env) {
  return env.JARVIS_STT === 'elevenlabs' ? 'elevenlabs' : 'local'
}

export function sttUrl(env = process.env) {
  return (env.JARVIS_STT_URL || 'http://127.0.0.1:8790').replace(/\/$/, '')
}

/** True when the local service answers its health check in time. */
export async function localSttHealthy(url = sttUrl(), fetchImpl = fetch, timeoutMs = 800) {
  try {
    const res = await fetchImpl(`${url}/health`, { signal: AbortSignal.timeout(timeoutMs) })
    return res.ok
  } catch {
    return false
  }
}

/** One recorded segment to the local service. Never throws. */
export async function transcribeLocal(bytes, type, url = sttUrl(), fetchImpl = fetch) {
  try {
    const res = await fetchImpl(`${url}/transcribe`, {
      method: 'POST',
      headers: { 'content-type': type || 'audio/webm' },
      body: bytes,
      signal: AbortSignal.timeout(30_000),
    })
    const body = await res
      .json()
      .catch(() => ({ error: 'bad response from the speech service' }))
    return { status: res.status, body }
  } catch (err) {
    return { status: 503, body: { error: `speech service unreachable: ${err?.message ?? err}` } }
  }
}
```

```js
/**
 * Which tier a tool call falls in. The rules live in policy.json (repo
 * defaults) and optionally ~/.jarvis/policy.json (the user's own). First
 * match wins; the defaults' deny rules always come first, so an override can
 * tighten the guard but never loosen a deny, and its "default" is ignored.
 */
import { existsSync, readFileSync } from 'node:fs'

export const TIERS = ['read', 'small', 'ask', 'deny']

/** `mcp__*Gmail*__send_message` → anchored RegExp. Only `*` is special. */
export function globToRegExp(glob) {
  const body = glob
    .split('*')
    .map((part) => part.replace(/[.+?^${}()|[\]\\]/g, '\\$&'))
    .join('.*')
  return new RegExp(`^${body}$`)
}

function validate(policy, source) {
  if (!policy || !Array.isArray(policy.rules)) {
    throw new Error(`${source}: "rules" must be an array`)
  }
  if (policy.default !== undefined && !TIERS.includes(policy.default)) {
    throw new Error(`${source}: default must be a tier of ${TIERS.join('/')}`)
  }
  policy.rules.forEach((rule, i) => {
    if (typeof rule.match !== 'string' || !TIERS.includes(rule.tier)) {
      throw new Error(`${source}: rule ${i} needs "match" and a tier of ${TIERS.join('/')}`)
    }
  })
  return policy
}

function compile(rule) {
  const m = rule.when?.matches
  return {
    ...rule,
    re: globToRegExp(rule.match),
    pattern: m ? new RegExp(m.pattern, (m.flags ?? '').replace(/g/g, '')) : null,
  }
}

const read = (path) => validate(JSON.parse(readFileSync(path, 'utf8')), String(path))

export function loadPolicy(defaultPath, overridePath) {
  const base = read(defaultPath)
  const extra = overridePath && existsSync(overridePath) ? read(overridePath) : { rules: [] }
  const denies = base.rules.filter((r) => r.tier === 'deny')
  const rest = base.rules.filter((r) => r.tier !== 'deny')
  return {
    rules: [...denies, ...extra.rules, ...rest].map(compile),
    default: base.default ?? 'ask',
  }
}

const present = (v) => !(v == null || v === '' || (Array.isArray(v) && v.length === 0))

function holds(rule, input) {
  const when = rule.when
  if (!when) return true
  if (when.has !== undefined) {
    const fields = Array.isArray(when.has) ? when.has : [when.has]
    if (!fields.some((f) => present(input?.[f]))) return false
  }
  if (rule.pattern) {
    const value = input?.[when.matches.field]
    if (typeof value !== 'string' || !rule.pattern.test(value)) return false
  }
  return true
}

/** The tier for one call. Unknown tools fall to the policy default ("ask"). */
export function tierOf(name, input, policy) {
  for (const rule of policy.rules) {
    if (rule.re.test(name) && holds(rule, input)) return rule.tier
  }
  return policy.default
}
```

```js
    .map((x) => (typeof x === 'string' ? x : x?.email))
    .filter(Boolean)

    return 'an unknown site'

export function humanSize(bytes) {
  if (!Number.isFinite(bytes) || bytes <= 0) return 'unknown size'
  const units = ['bytes', 'KB', 'MB', 'GB']
  let n = bytes
  let i = 0
  while (n >= 1024 && i < units.length - 1) {
    n /= 1024
    i++
  }
  return i === 0 ? `${n} bytes` : `${n.toFixed(1)} ${units[i]}`
}

/** Size and filename for a download confirmation; null when not allowed. */
export async function headInfo(url, fetchImpl = fetch, vet) {
  if (vet && (await vet(url))) return null
  const res = await fetchImpl(url, { method: 'HEAD', redirect: 'follow', signal: AbortSignal.timeout(5000) })
  const size = Number(res.headers.get('content-length'))
  const cd = res.headers.get('content-disposition') || ''
  const m = /filename\*?=(?:UTF-8'')?"?([^";]+)"?/i.exec(cd)
  let filename = m ? decodeURIComponent(m[1]) : ''
  if (!filename) {
    try {
      filename = decodeURIComponent(new URL(res.url || url).pathname.split('/').pop() || '')
    } catch {
      filename = ''
    }
  }
  return { size: Number.isFinite(size) && size > 0 ? size : NaN, filename }
}

  const tool = toolPart(name)
  const server = serverPart(name)
  const subject = `"${short(input.subject, 60) || 'no subject'}"`

  if (name === 'Bash' || tool === 'PowerShell') return `run the command ${short(input.command)}`

  if (/Gmail/i.test(server)) {
    if (tool === 'send_message') {
      return input.draftId ? 'send the email draft' : `send an email to ${who(input.to)} about ${subject}`
    }
    if (tool === 'reply') return 'send a reply in that email thread'
    if (tool === 'forward') return `forward that email to ${who(input.to)}`
    if (/trash|delete/.test(tool)) return 'move that email to the trash'
  }
  if (/Microsoft/i.test(server)) {
    if (tool === 'outlook_send_mail') return `send an email to ${who(input.to)} about ${subject}`
    if (tool === 'outlook_send_draft') return 'send the Outlook draft'
    if (tool === 'outlook_forward_mail') return `forward that email to ${who(input.to)}`
    if (tool === 'outlook_create_event') {
      return `create "${short(input.subject, 60)}" in the calendar and invite ${who(input.attendees)}`
    }
  }
  if (/Calendar/i.test(server)) {
    if (tool === 'create_event') {
      return `create "${short(input.summary, 60)}" in the calendar and invite ${who(input.attendees ?? input.attendeeEmails)}`
    }
    if (tool === 'update_event') return 'change that calendar event'
    if (tool === 'delete_event') return 'delete that calendar event'
    if (tool === 'respond_to_event') return 'answer that calendar invitation'
  }
  if (/Drive/i.test(server) && tool === 'share_file') {
    if (input.permissionId === 'anyoneWithLink') return 'share that Drive file with anyone who has the link'
    return `share that Drive file with ${short(input.emailAddress, 60) || 'someone'}`
  }
  if (tool === 'download_file') {
    const info = head ? await head(input.url).catch(() => null) : null
    return `download ${info?.filename || 'a file'} from ${host(input.url)}, ${humanSize(info?.size)}`
  }

  if (tool === 'forget') return `forget what I remember about "${short(input.match, 60)}"`

  const label = tool.replace(/[_-]+/g, ' ')
  const from = server.replace(/^claude_ai_/, '').replace(/[_-]+/g, ' ')
  return from ? `use ${label} from ${from}` : `use ${label}`
}
```

```js
/**
 * The guard. One per connection. Every tool call is decided by tier:
 *
 *   read  — runs.
 *   small — runs (reversible, logged).
 *   ask   — the HUD asks out loud; only a clear yes runs it.
 *   deny  — never runs.
 *
 * Argument checks from policy.mjs (file roots, credential paths, private
 * addresses) come first and can only make the answer stricter. Any exception
 * while deciding is a deny. Every decision goes to the audit log.
 */
import { checkToolUse } from './policy.mjs'
import { tierOf } from './tiers.mjs'
import { summarize } from './summarize.mjs'

const REUSE_MS = 30_000
const SAID_NO =
  'The user said no. Do not try again or find another way to do it; say in one short sentence that you have left it.'

export function createGuard({ policy, confirm, audit, ctx, head, dryRun = false, log = () => {}, now = Date.now }) {
  const recent = new Map()
  const keyOf = (name, input) => `${name}\u0000${JSON.stringify(input ?? {})}`

  async function decide(name, input) {
    const args = checkToolUse(name, input, { allowWrites: true, cwd: ctx.cwd, roots: ctx.roots })
    if (!args.allow) return { verdict: 'deny', tier: 'deny', reason: args.reason }
    if (name === 'WebFetch' && ctx.fetchProblem) {
      const problem = await ctx.fetchProblem(input?.url)
      if (problem) return { verdict: 'deny', tier: 'deny', reason: `Blocked: that address cannot be fetched (${problem}).` }
    }
    const tier = tierOf(name, input, policy)
    if (tier === 'deny') {
      return { verdict: 'deny', tier, reason: 'Blocked: that action is never allowed on this machine. Tell the user in one sentence.' }
    }
    if (tier === 'read') return { verdict: 'allow', tier }
    if (dryRun) {
      return { verdict: 'deny', tier, dryRun: true, reason: `Dry run: ${name} was recorded but not run. Continue as if it had worked.` }
    }
    if (tier === 'small') return { verdict: 'allow', tier }
    const summary = await summarize(name, input, { head })
    const answer = await confirm({ summary, tool: name })
    if (answer?.approved === true) return { verdict: 'allow', tier, summary, answer: answer.answer ?? 'yes' }
    return { verdict: 'deny', tier, summary, answer: answer?.answer ?? 'no', reason: SAID_NO }
  }

  async function judge(name, input) {
    let d
    try {
      d = await decide(name, input)
    } catch (err) {
      d = {
        verdict: 'deny',
        tier: 'error',
        reason: 'Blocked: the safety check failed, so nothing was done.',
        error: String(err?.message ?? err),
      }
    }
    recent.set(keyOf(name, input), { at: now(), d })
    audit.record({
      tool: name,
      tier: d.tier,
      verdict: d.verdict,
      summary: d.summary,
      answer: d.answer,
      dryRun: d.dryRun,
      error: d.error,
      input,
    })
    log(`[jarvis] tool ${name} -> ${d.tier}/${d.verdict}`)
    return d
  }

  /** PreToolUse hook: runs before every call and always decides afresh. */
  async function hook(input) {
    const d = await judge(input.tool_name, input.tool_input)
    return {
      hookSpecificOutput: {
        hookEventName: 'PreToolUse',
        permissionDecision: d.verdict,
        ...(d.verdict === 'deny' ? { permissionDecisionReason: d.reason } : {}),
      },
    }
  }

  /** Second gate. Reuses the hook's decision for the same call. */
  async function canUseTool(name, input) {
    const hit = recent.get(keyOf(name, input))
    const d = hit && now() - hit.at < REUSE_MS ? hit.d : await judge(name, input)
    return d.verdict === 'allow' ? { behavior: 'allow', updatedInput: input } : { behavior: 'deny', message: d.reason }
  }

  return { hook, canUseTool, decide }
}
```

```ts
/** How a spoken reply to "Shall I?" is read. */
export type Answer = 'yes' | 'no' | 'unclear'

const YES = /^(yes|yeah|yep|yup|sure|do it|go ahead|go|okay|ok|confirm|please do|ja|japp|kör|gör det)\b/i
const NO = /^(no|nope|nah|stop|cancel|don'?t|abort|never mind|nej|avbryt|stopp|låt bli)\b/i

export function parseAnswer(text: string): Answer {
  const said = text
    .trim()
    .replace(/^(hey |ok |okay )?jarvis[,.!\s]*/i, '')
    .replace(/[.!?,]+$/g, '')
    .trim()
    .toLowerCase()
  if (!said) return 'unclear'
  const yes = YES.test(said)
  const no = NO.test(said)
  if (yes === no) return 'unclear'
  return yes ? 'yes' : 'no'
}

export const CONFIRM_TIMEOUT_MS = 20_000

type ConfirmIO = {
  say: (line: string) => void
  arm: () => void
  done: (approved: boolean, answer: string) => void
}

/**
 * The yes/no exchange as a small state machine: ask, accept one unclear
 * answer and ask again, then give up. `arm` (re)starts the caller's
 * CONFIRM_TIMEOUT_MS timer, which calls `timeout()`. `done` fires once.
 */
export function confirmFlow(summary: string, io: ConfirmIO) {
  let attempts = 0
  let finished = false
  const finish = (approved: boolean, answer: string) => {
    if (finished) return
    finished = true
    io.done(approved, answer)
  }
  const ask = (line: string) => {
    io.say(line)
    io.arm()
  }
  ask(`I'm about to ${summary}. Shall I?`)
  return {
    hear(text: string) {
      if (finished) return
      const a = parseAnswer(text)
      if (a === 'yes') return finish(true, text)
      if (a === 'no') return finish(false, text)
      attempts += 1
      if (attempts >= 2) return finish(false, `unclear: ${text}`)
      ask('Sorry, sir — yes or no?')
    },
    timeout() {
      finish(false, 'timeout')
    },
  }
}
```

```python
"""Things that must never be written to memory."""
import re

_PATTERNS = [
    re.compile(r"sk-[A-Za-z0-9_-]{16,}"),
    re.compile(r"gh[pousr]_[A-Za-z0-9]{20,}"),
    re.compile(r"AKIA[0-9A-Z]{16}"),
    re.compile(r"xox[abpr]-[A-Za-z0-9-]{10,}"),
    re.compile(r"(?i)\b(password|passwd|pwd|lösenord|secret|token|api[_-]?key)\s*[:=]\s*\S+"),
]
_DIGITS = re.compile(r"(?:\d[ -]?){13,19}")


def _luhn(number: str) -> bool:
    digits = [int(c) for c in number if c.isdigit()]
    if not 13 <= len(digits) <= 19:
        return False
    total = 0
    for i, d in enumerate(reversed(digits)):
        if i % 2 == 1:
            d *= 2
            if d > 9:
                d -= 9
        total += d
    return total % 10 == 0


def contains_secret(text: str) -> bool:
    if any(p.search(text) for p in _PATTERNS):
        return True
    return any(_luhn(m.group(0)) for m in _DIGITS.finditer(text))
```

```python
"""Markdown files are the memory; SQLite is only a search index over them."""
from __future__ import annotations

import re
import sqlite3
from datetime import date
from pathlib import Path
from typing import Callable

from .secrets import contains_secret

_SLUG = re.compile(r"[^a-z0-9]+")


def topic_slug(topic: str) -> str:
    t = topic.lower().translate(str.maketrans("åäö", "aao"))
    return _SLUG.sub("-", t).strip("-") or "allmant"


class SecretRefused(ValueError):
    pass


class MemoryStore:
    def __init__(self, root: Path, today: Callable[[], date] = date.today):
        self.root = Path(root)
        self.facts = self.root / "fakta"
        self.logs = self.root / "logg"
        self.today = today
        for folder in (self.root, self.facts, self.logs):
            folder.mkdir(parents=True, exist_ok=True)
        profile = self.root / "profil.md"
        if not profile.exists():
            profile.write_text("# Profil\n", encoding="utf-8")
        self._db = sqlite3.connect(str(self.root / "index.sqlite"), check_same_thread=False)
        self.fts = self._try_fts()
        self.reindex()

    # -- index -------------------------------------------------------------

    def _plain_table(self) -> bool:
        self._db.execute("DROP TABLE IF EXISTS notes")
        self._db.execute("CREATE TABLE notes (file TEXT, line INTEGER, text TEXT)")
        return False

    def _try_fts(self) -> bool:
        try:
            self._db.execute("DROP TABLE IF EXISTS notes")
            self._db.execute("CREATE VIRTUAL TABLE notes USING fts5(file, line, text)")
            return True
        except sqlite3.OperationalError:
            return self._plain_table()

    def _files(self):
        yield self.root / "profil.md"
        yield from sorted(self.facts.glob("*.md"))
        yield from sorted(self.logs.glob("*.md"))

    def reindex(self) -> None:
        rows = []
        for f in self._files():
            for i, line in enumerate(f.read_text(encoding="utf-8").splitlines(), start=1):
                text = line.strip().lstrip("-").strip()
                if text and not text.startswith("#"):
                    rows.append((f.relative_to(self.root).as_posix(), i, text))
        self._db.execute("DELETE FROM notes")
        self._db.executemany("INSERT INTO notes (file, line, text) VALUES (?, ?, ?)", rows)
        self._db.commit()

    # -- tools -------------------------------------------------------------

    def recall(self, query: str, limit: int = 5) -> list[dict]:
        words = [w for w in re.findall(r"\w+", query.lower()) if len(w) > 1]
        if not words:
            return []
        if self.fts:
            match = " OR ".join(f'"{w}"' for w in words)
            cur = self._db.execute(
                "SELECT file, line, text FROM notes WHERE notes MATCH ? ORDER BY rank LIMIT ?",
                (match, limit),
            )
        else:
            clause = " OR ".join("lower(text) LIKE ?" for _ in words)
            cur = self._db.execute(
                f"SELECT file, line, text FROM notes WHERE {clause} LIMIT ?",
                (*[f"%{w}%" for w in words], limit),
            )
        return [{"file": f, "line": int(n), "text": t} for f, n, t in cur.fetchall()]

    def remember(self, text: str, topic: str) -> dict:
        text = " ".join(text.split())
        if not text:
            raise ValueError("nothing to remember")
        if contains_secret(text):
            raise SecretRefused("that looks like a password, key or card number, so it was not saved")
        path = self.facts / f"{topic_slug(topic)}.md"
        if not path.exists():
            path.write_text(f"# {topic.strip() or 'Allmänt'}\n", encoding="utf-8")
        with path.open("a", encoding="utf-8") as fh:
            fh.write(f"- {text} ({self.today().isoformat()})\n")
        self.reindex()
        return {"file": f"fakta/{path.name}", "text": text}

    def forget(self, match: str) -> int:
        needle = match.strip().lower()
        if len(needle) < 3:
            raise ValueError("say a little more about what to forget")
        removed = 0
        for f in self.facts.glob("*.md"):
            lines = f.read_text(encoding="utf-8").splitlines(keepends=True)
            kept = [l for l in lines if l.startswith("#") or needle not in l.lower()]
            if len(kept) != len(lines):
                removed += len(lines) - len(kept)
                f.write_text("".join(kept), encoding="utf-8")
        self.reindex()
        return removed

    def log_day(self, summary: str) -> dict:
        summary = " ".join(summary.split())
        if not summary:
            raise ValueError("empty summary")
        if contains_secret(summary):
            raise SecretRefused("the summary contained something secret, so it was not saved")
        day = self.today().isoformat()
        path = self.logs / f"{day}.md"
        if not path.exists():
            path.write_text(f"# {day}\n", encoding="utf-8")
        with path.open("a", encoding="utf-8") as fh:
            fh.write(f"- {summary}\n")
        self.reindex()
        return {"file": f"logg/{path.name}"}
```

```python
from __future__ import annotations

import os
from pathlib import Path

from mcp.server.fastmcp import FastMCP

from .store import MemoryStore, SecretRefused


def default_root() -> Path:
    return Path(os.environ.get("JARVIS_MEMORY_DIR", Path.home() / ".jarvis" / "memory"))


def build(store: MemoryStore) -> FastMCP:
    mcp = FastMCP("jarvis-memory")

    @mcp.tool()
    def recall(query: str, limit: int = 5) -> list[dict]:
        """Search what JARVIS remembers about the user. Use before answering anything about their own life, plans or preferences."""
        return store.recall(query, max(1, min(limit, 20)))

    @mcp.tool()
    def remember(text: str, topic: str) -> dict:
        """Save one lasting fact the user told you, or asked you to remember, under a short topic such as 'golf' or 'studies'."""
        try:
            return store.remember(text, topic)
        except SecretRefused as err:
            return {"error": str(err)}

    @mcp.tool()
    def forget(match: str) -> dict:
        """Remove remembered facts that contain this text."""
        return {"removed": store.forget(match)}

    @mcp.tool()
    def log_day(summary: str) -> dict:
        """Append a two-sentence summary of today's conversation to the daily log. Call it when the conversation ends."""
        try:
            return store.log_day(summary)
        except SecretRefused as err:
            return {"error": str(err)}

    return mcp


def main() -> None:
    build(MemoryStore(default_root())).run()
```

```python
"""The Jarvis folder, its layout and its naming rule (spec §4.7)."""
from __future__ import annotations

import os
import re
import time
import zipfile
from datetime import date
from pathlib import Path

EXECUTABLE = {".exe", ".msi", ".bat", ".cmd", ".ps1", ".scr", ".appx", ".msix", ".vbs", ".js", ".jar", ".com"}
KINDS = {
    "Dokument": {".pdf", ".doc", ".docx", ".odt", ".txt", ".md", ".rtf", ".xls", ".xlsx", ".csv", ".ppt", ".pptx"},
    "Bilder": {".jpg", ".jpeg", ".png", ".gif", ".webp", ".heic", ".svg", ".bmp", ".tif", ".tiff"},
    "Video": {".mp4", ".mov", ".mkv", ".webm", ".avi", ".m4v"},
    "Ljud": {".mp3", ".wav", ".flac", ".m4a", ".ogg", ".opus", ".aac"},
    "Program": EXECUTABLE | {".7z", ".rar"},
}
LAYOUT = [
    "Nedladdningar/Dokument", "Nedladdningar/Bilder", "Nedladdningar/Video",
    "Nedladdningar/Ljud", "Nedladdningar/Program",
    "Video/Original", "Video/Shorts", "Mejlbilagor", "Dokument", "Arbetsyta",
]
_TRANSLIT = str.maketrans({"å": "a", "ä": "a", "ö": "o", "Å": "a", "Ä": "a", "Ö": "o", "é": "e", "ü": "u"})


def slugify(text: str, max_len: int = 60) -> str:
    t = text.translate(_TRANSLIT).lower()
    t = re.sub(r"[^a-z0-9]+", "-", t).strip("-")
    return t[:max_len].rstrip("-") or "fil"


def dated_name(description: str, ext: str, today: date) -> str:
    if ext and not ext.startswith("."):
        ext = f".{ext}"
    return f"{today.isoformat()}_{slugify(description)}{ext.lower()}"


def kind_for(name: str) -> str:
    ext = Path(name).suffix.lower()
    for kind, exts in KINDS.items():
        if ext in exts:
            return kind
    return "Dokument"


def kind_for_file(path: Path) -> str:
    """Like kind_for, but a zip is a program if anything inside would run."""
    path = Path(path)
    if path.suffix.lower() != ".zip":
        return kind_for(path.name)
    try:
        with zipfile.ZipFile(path) as z:
            names = z.namelist()
    except (zipfile.BadZipFile, OSError):
        return "Program"  # can't look inside: treat it as dangerous
    return "Program" if any(Path(n).suffix.lower() in EXECUTABLE for n in names) else "Dokument"


def unique_path(folder: Path, name: str) -> Path:
    folder = Path(folder)
    candidate = folder / name
    stem, suffix = Path(name).stem, Path(name).suffix
    n = 2
    while candidate.exists():
        candidate = folder / f"{stem}-{n}{suffix}"
        n += 1
    return candidate


def jarvis_root() -> Path:
    return Path(os.environ.get("JARVIS_ROOT", Path.home() / "Jarvis"))


def ensure_layout(root: Path) -> None:
    for part in LAYOUT:
        (Path(root) / part).mkdir(parents=True, exist_ok=True)


def cleanup_workspace(root: Path, days: int = 7, now: float | None = None) -> int:
    cutoff = (now if now is not None else time.time()) - days * 86400
    removed = 0
    for f in (Path(root) / "Arbetsyta").rglob("*"):
        if f.is_file() and f.stat().st_mtime < cutoff:
            f.unlink()
            removed += 1
    return removed
```

```python
def inside(root: Path, path: Path) -> bool:
    try:
        Path(path).resolve().relative_to(Path(root).resolve())
        return True
    except ValueError:
        return False


def check_source(path: Path, allowed: list[Path], home: Path) -> Path:
    real = Path(path).expanduser().resolve()
    if inside(Path(home) / ".jarvis", real) or _SECRET_NAME.match(real.name):
        raise ValueError("that file is off limits")
    if not any(inside(root, real) for root in allowed):
        raise ValueError("JARVIS may only use files in the Jarvis, Downloads, Videos, Desktop, Documents or temp folders")
    if not real.is_file():
        raise ValueError("that file does not exist")
    return real


def check_sort_folder(path: Path, home: Path) -> Path:
    real = Path(path).expanduser().resolve()
    home = Path(home).resolve()
    if real == home or not inside(home, real):
        raise ValueError("pick a folder inside your home folder")
    rel = real.relative_to(home)
    if any(part.startswith(".") for part in rel.parts) or rel.parts[0].lower() == "appdata":
        raise ValueError("that folder is off limits")
    if not real.is_dir():
        raise ValueError("that folder does not exist")
    return real
```

```python
"""Download one file into the Jarvis folder. Public addresses only; never run."""
from __future__ import annotations

import ipaddress
import os
import re
import socket
import subprocess
import urllib.request
from datetime import date
from pathlib import Path
from urllib.parse import unquote, urlparse

from .naming import dated_name, kind_for_file, slugify, unique_path

MAX_DOWNLOAD = 4 * 1024**3


class DownloadRefused(ValueError):
    pass


def host_is_public(host: str, resolve=socket.getaddrinfo) -> bool:
    try:
        infos = resolve(host, None)
    except (socket.gaierror, UnicodeError):
        return False
    for info in infos:
        ip = ipaddress.ip_address(info[4][0].split("%")[0])
        if not ip.is_global:
            return False
    return bool(infos)


class _SafeRedirect(urllib.request.HTTPRedirectHandler):
    def __init__(self, public):
        super().__init__()
        self.public = public

    def redirect_request(self, req, fp, code, msg, headers, newurl):
        target = urlparse(newurl)
        if target.scheme not in ("http", "https") or not self.public(target.hostname or ""):
            raise DownloadRefused("the link redirected to a private or local address")
        return super().redirect_request(req, fp, code, msg, headers, newurl)


def _filename(url: str, headers) -> str:
    cd = headers.get("Content-Disposition", "") or ""
    m = re.search(r"filename\*?=(?:UTF-8'')?\"?([^\";]+)\"?", cd, re.I)
    if m:
        return Path(unquote(m.group(1))).name
    return Path(unquote(urlparse(url).path)).name or "download"


def defender_scan(path: Path, run=subprocess.run) -> bool:
    """True if Microsoft Defender scanned the file and found nothing."""
    mpcmd = Path(os.environ.get("ProgramFiles", r"C:\Program Files")) / "Windows Defender" / "MpCmdRun.exe"
    if not mpcmd.exists():
        return False
    result = run(
        [str(mpcmd), "-Scan", "-ScanType", "3", "-File", str(path), "-DisableRemediation"],
        capture_output=True, text=True, timeout=300,
    )
    return result.returncode == 0


def download(url: str, root: Path, today: date, public=host_is_public, scan=defender_scan, timeout: int = 60) -> dict:
    parsed = urlparse(url)
    if parsed.scheme not in ("http", "https") or not parsed.hostname:
        raise DownloadRefused("only http and https links can be downloaded")
    if not public(parsed.hostname):
        raise DownloadRefused("that address is on a private or local network")

    root = Path(root)
    work = root / "Arbetsyta"
    work.mkdir(parents=True, exist_ok=True)
    opener = urllib.request.build_opener(_SafeRedirect(public))
    request = urllib.request.Request(url, headers={"User-Agent": "JARVIS/1"})
    with opener.open(request, timeout=timeout) as res:
        name = _filename(res.geturl(), res.headers)
        stem, ext = Path(name).stem, Path(name).suffix
        staged = unique_path(work, f".part-{slugify(stem)}{ext.lower()}")
        size = 0
        with staged.open("wb") as fh:
            while chunk := res.read(256 * 1024):
                size += len(chunk)
                if size > MAX_DOWNLOAD:
                    fh.close()
                    staged.unlink()
                    raise DownloadRefused("the file is larger than 4 GB")
                fh.write(chunk)

    kind = kind_for_file(staged)
    folder = root / "Nedladdningar" / kind
    folder.mkdir(parents=True, exist_ok=True)
    dest = unique_path(folder, dated_name(stem, ext, today))
    staged.replace(dest)
    scanned = scan(dest) if kind == "Program" else None
    note = "Saved. Programs are never run automatically." if kind == "Program" else "Saved."
    return {"path": str(dest), "size": size, "kind": kind, "scanned": scanned, "note": note}
```

```python
"""Vertical shorts from a video: transcript with timestamps, then ffmpeg cuts."""
from __future__ import annotations

import hashlib
import json
import subprocess
import urllib.request
from datetime import date
from pathlib import Path

from .naming import dated_name, unique_path

CLIP_MIN, CLIP_MAX = 15.0, 60.0
MAX_AUDIO = 25 * 1024 * 1024


def to_srt_time(t: float) -> str:
    ms = int(round(max(t, 0) * 1000))
    h, ms = divmod(ms, 3_600_000)
    m, ms = divmod(ms, 60_000)
    s, ms = divmod(ms, 1000)
    return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"


def build_srt(segments: list[dict], start: float, end: float) -> str:
    blocks = []
    for seg in segments:
        if seg["end"] <= start or seg["start"] >= end:
            continue
        text = str(seg.get("text", "")).strip()
        if not text:
            continue
        a = max(seg["start"], start) - start
        b = min(seg["end"], end) - start
        blocks.append(f"{len(blocks) + 1}\n{to_srt_time(a)} --> {to_srt_time(b)}\n{text}\n")
    return "\n".join(blocks)


def validate_clips(clips: list[dict], duration: float) -> list[dict]:
    if not 1 <= len(clips) <= 10:
        raise ValueError("choose between 1 and 10 clips")
    out = []
    for i, clip in enumerate(clips, start=1):
        start, end = float(clip["start"]), float(clip["end"])
        if start < 0 or end > duration + 0.5:
            raise ValueError(f"clip {i} is outside the video")
        length = end - start
        if not CLIP_MIN - 0.5 <= length <= CLIP_MAX + 0.5:
            raise ValueError(f"clip {i} is {length:.0f} seconds; shorts must be 15 to 60 seconds")
        out.append({"start": start, "end": min(end, duration), "title": str(clip.get("title", ""))[:80]})
    return out


def ffmpeg_args(src: Path, start: float, end: float, srt_name: str, out_name: str) -> list[str]:
    vf = "crop='min(iw,ih*9/16)':ih,scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920"
    if srt_name:
        vf += f",subtitles={srt_name}:force_style='FontSize=14,Outline=2,MarginV=60'"
    return [
        "ffmpeg", "-hide_banner", "-loglevel", "error", "-y",
        "-ss", f"{start:.2f}", "-to", f"{end:.2f}", "-i", str(src),
        "-vf", vf,
        "-c:v", "libx264", "-preset", "veryfast", "-crf", "23",
        "-c:a", "aac", "-b:a", "128k", "-movflags", "+faststart",
        out_name,
    ]


def probe_duration(src: Path, run=subprocess.run) -> float:
    r = run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration", "-of", "csv=p=0", str(src)],
        capture_output=True, text=True,
    )
    if r.returncode != 0:
        raise RuntimeError("could not read the video's length")
    return float(r.stdout.strip())


def _post(url: str, data: bytes, ctype: str) -> dict:
    req = urllib.request.Request(url, data=data, method="POST", headers={"Content-Type": ctype})
    with urllib.request.urlopen(req, timeout=600) as res:
        return json.loads(res.read())


def _cache_key(src: Path) -> str:
    st = src.stat()
    return hashlib.sha1(f"{src.resolve()}|{st.st_size}|{st.st_mtime_ns}".encode()).hexdigest()[:16]


def transcribe_video(src: Path, work: Path, stt_url: str, post=_post, run=subprocess.run) -> dict:
    src = Path(src)
    cache = Path(work) / "transcripts" / f"{_cache_key(src)}.json"
    if cache.exists():
        return json.loads(cache.read_text(encoding="utf-8"))
    cache.parent.mkdir(parents=True, exist_ok=True)
    audio = cache.with_suffix(".ogg")
    r = run(
        ["ffmpeg", "-hide_banner", "-loglevel", "error", "-y", "-i", str(src),
         "-vn", "-ac", "1", "-ar", "16000", "-c:a", "libopus", "-b:a", "24k", str(audio)],
        capture_output=True, text=True,
    )
    if r.returncode != 0:
        raise RuntimeError(f"could not read the audio: {r.stderr.strip()[-300:]}")
    data = audio.read_bytes()
    audio.unlink()
    if len(data) > MAX_AUDIO:
        raise ValueError("the video is too long to transcribe in one go")
    body = post(f"{stt_url.rstrip('/')}/transcribe?segments=1", data, "audio/ogg")
    result = {
        "text": body.get("text", ""),
        "language": body.get("language"),
        "segments": body.get("segments", []),
        "duration": probe_duration(src, run),
    }
    cache.write_text(json.dumps(result), encoding="utf-8")
    return result


def make_shorts(src: Path, clips: list[dict], name: str, root: Path, today: date,
                transcript: list[dict] | None = None, run=subprocess.run) -> dict:
    src = Path(src)
    chosen = validate_clips(clips, probe_duration(src, run))
    shorts = Path(root) / "Video" / "Shorts"
    shorts.mkdir(parents=True, exist_ok=True)
    out_dir = unique_path(shorts, dated_name(name, "", today))
    out_dir.mkdir(parents=True)
    files = []
    for i, clip in enumerate(chosen, start=1):
        base = f"short-{i:02d}"
        srt_name = ""
        if transcript:
            srt = build_srt(transcript, clip["start"], clip["end"])
            if srt:
                (out_dir / f"{base}.srt").write_text(srt, encoding="utf-8")
                srt_name = f"{base}.srt"
        # Run inside the output folder so the subtitles path needs no escaping
        # (Windows drive letters and backslashes break ffmpeg's filter syntax).
        r = run(ffmpeg_args(src, clip["start"], clip["end"], srt_name, f"{base}.mp4"),
                cwd=out_dir, capture_output=True, text=True)
        if r.returncode != 0:
            raise RuntimeError(f"ffmpeg failed on clip {i}: {r.stderr.strip()[-300:]}")
        files.append(str(out_dir / f"{base}.mp4"))
    return {"folder": str(out_dir), "files": files}
```

```python
"""Sort a folder into type subfolders: plan first, move only on apply."""
from __future__ import annotations

import hashlib
import json
import re
import time
from collections import Counter
from pathlib import Path

from .naming import kind_for_file, unique_path


def plan_sort(folder: Path, plans: Path, now=time.time) -> dict:
    folder = Path(folder)
    moves = []
    for f in sorted(folder.iterdir()):
        if not f.is_file() or f.name.startswith("."):
            continue
        st = f.stat()
        moves.append({"from": str(f), "kind": kind_for_file(f), "size": st.st_size, "mtime_ns": st.st_mtime_ns})
    plan_id = hashlib.sha1(f"{folder.resolve()}|{now()}".encode()).hexdigest()[:10]
    plans = Path(plans)
    plans.mkdir(parents=True, exist_ok=True)
    (plans / f"{plan_id}.json").write_text(json.dumps({"folder": str(folder), "moves": moves}), encoding="utf-8")
    counts = Counter(m["kind"] for m in moves)
    summary = ", ".join(f"{n} to {kind}" for kind, n in counts.most_common()) or "nothing to move"
    return {"plan_id": plan_id, "files": len(moves), "summary": summary}


def apply_sort(plan_id: str, plans: Path) -> dict:
    path = Path(plans) / f"{plan_id}.json"
    if not re.fullmatch(r"[0-9a-f]{10}", plan_id) or not path.exists():
        raise ValueError("unknown sorting plan")
    plan = json.loads(path.read_text(encoding="utf-8"))
    folder = Path(plan["folder"])
    moved = skipped = 0
    for m in plan["moves"]:
        src = Path(m["from"])
        try:
            st = src.stat()
        except FileNotFoundError:
            skipped += 1
            continue
        if st.st_size != m["size"] or st.st_mtime_ns != m["mtime_ns"]:
            skipped += 1
            continue
        target = folder / m["kind"]
        target.mkdir(exist_ok=True)
        src.replace(unique_path(target, src.name))
        moved += 1
    path.unlink()
    return {"moved": moved, "skipped": skipped}
```

```python
"""Put a file in its place in the Jarvis folder, with a dated name."""
from __future__ import annotations

import shutil
from datetime import date
from pathlib import Path

from .naming import dated_name, kind_for_file, unique_path
from .paths import inside

STORE_KINDS = {"attachment", "document", "download", "video"}


def store_file(source: Path, kind: str, description: str, root: Path, today: date, movable_roots: list[Path]) -> dict:
    source = Path(source)
    if kind not in STORE_KINDS:
        raise ValueError(f"kind must be one of {', '.join(sorted(STORE_KINDS))}")
    if not source.is_file():
        raise ValueError("that file does not exist")
    root = Path(root)
    if kind == "attachment":
        folder = root / "Mejlbilagor" / today.strftime("%Y-%m")
    elif kind == "document":
        folder = root / "Dokument"
    elif kind == "video":
        folder = root / "Video" / "Original"
    else:
        folder = root / "Nedladdningar" / kind_for_file(source)
    folder.mkdir(parents=True, exist_ok=True)
    dest = unique_path(folder, dated_name(description or source.stem, source.suffix, today))
    # Files JARVIS made itself (workspace, temp) move; the user's own files are copied.
    if any(inside(r, source) for r in movable_roots):
        shutil.move(str(source), dest)
        action = "moved"
    else:
        shutil.copy2(source, dest)
        action = "copied"
    return {"path": str(dest), "action": action}
```

```python
"""jarvis-media: downloads, shorts, sorting and filing as MCP tools."""
from __future__ import annotations

import os
import tempfile
from datetime import date
from pathlib import Path

from mcp.server.fastmcp import FastMCP

from .download import DownloadRefused, download
from .naming import cleanup_workspace, ensure_layout, jarvis_root
from .paths import check_sort_folder, check_source
from .shorts import make_shorts as _make_shorts
from .shorts import transcribe_video as _transcribe
from .sorting import apply_sort as _apply_sort
from .sorting import plan_sort as _plan_sort
from .storing import store_file as _store_file


def build(root: Path, home: Path, stt_url: str, today=date.today) -> FastMCP:
    mcp = FastMCP("jarvis-media")
    root, home = Path(root), Path(home)
    work = root / "Arbetsyta"
    plans = home / ".jarvis" / "plans"
    temp = Path(tempfile.gettempdir())
    sources = [root, temp, home / "Downloads", home / "Videos", home / "Desktop", home / "Documents"]

    @mcp.tool()
    def download_file(url: str) -> dict:
        """Download one file from a direct http(s) link into the Jarvis downloads folder. Programs are scanned and never run."""
        try:
            return download(url, root, today())
        except DownloadRefused as err:
            return {"error": str(err)}

    @mcp.tool()
    def transcribe_video(path: str) -> dict:
        """Transcript of a video with timestamps in seconds. Use it to choose 15-60 second clips for shorts."""
        out = _transcribe(check_source(Path(path), sources, home), work, stt_url)
        segments = out["segments"]
        return {**out, "segments": segments[:600], "truncated": len(segments) > 600}

    @mcp.tool()
    def make_shorts(path: str, clips: list[dict], name: str) -> dict:
        """Cut vertical shorts with burned-in subtitles. clips: [{"start": s, "end": s, "title": "..."}], each 15-60 seconds. The original is never changed."""
        src = check_source(Path(path), sources, home)
        try:
            transcript = _transcribe(src, work, stt_url)["segments"]
        except Exception:
            transcript = None  # subtitles are a bonus; the cut still works without them
        return _make_shorts(src, clips, name, root, today(), transcript)

    @mcp.tool()
    def plan_sort(folder: str) -> dict:
        """Propose sorting a folder's files into Dokument, Bilder, Video, Ljud and Program subfolders. Nothing moves until apply_sort."""
        return _plan_sort(check_sort_folder(Path(folder), home), plans)

    @mcp.tool()
    def apply_sort(plan_id: str) -> dict:
        """Carry out a plan from plan_sort. Files changed since the plan are skipped."""
        return _apply_sort(plan_id, plans)

    @mcp.tool()
    def store_file(source: str, kind: str, description: str) -> dict:
        """Put a file in its place in the Jarvis folder with a dated name. kind: attachment, document, download or video."""
        src = check_source(Path(source), sources, home)
        return _store_file(src, kind, description, root, today(), [work, temp])

    return mcp


def main() -> None:
    root = jarvis_root()
    ensure_layout(root)
    cleanup_workspace(root, days=7)
    build(root, Path.home(), os.environ.get("JARVIS_STT_URL", "http://127.0.0.1:8790")).run()
```

```js
/**
 * When the Claude plan's usage limit stops a turn, JARVIS should say so
 * rather than go quiet. Returns the sentence to speak, or null.
 */
const PREFIX = "I've hit the usage limit on your Claude plan."

export function limitNotice(text) {
  const s = String(text ?? '')
  const epoch = /limit reached\|(\d{10})/i.exec(s)
  if (epoch) {
    const at = new Date(Number(epoch[1]) * 1000)
    const hh = String(at.getHours()).padStart(2, '0')
    const mm = String(at.getMinutes()).padStart(2, '0')
    return `${PREFIX} It resets at ${hh}:${mm}.`
  }
  const resets = /limit.*?resets?\s+(?:at\s+)?(\d{1,2}(?::\d{2})?\s*(?:am|pm)?)/i.exec(s)
  if (resets) return `${PREFIX} It resets at ${resets[1].trim()}.`
  if (/(usage|rate)[ _-]?limit/i.test(s)) return `${PREFIX} Try again a little later.`
  return null
}
```

```js
/**
 * Like run(), but a crash restarts the process instead of stopping
 * everything — at most `maxPerMinute` times, then it stays down. stderr is
 * also kept in ~/.jarvis/logs/<name>.log.
 */
function supervise(name, command, args, colour, env = {}, { maxPerMinute = 3 } = {}) {
  const label = paint(name, colour)
  const logDir = join(homedir(), '.jarvis', 'logs')
  mkdirSync(logDir, { recursive: true })
  const logFile = join(logDir, `${name}.log`)
  const starts = []
  const launch = () => {
    if (stopping) return
    const now = Date.now()
    while (starts.length && now - starts[0] > 60_000) starts.shift()
    if (starts.length >= maxPerMinute) {
      console.log(label(`crashed ${maxPerMinute} times in a minute; leaving it stopped (see ${logFile})`))
      return
    }
    starts.push(now)
    const child = spawn(command, args, { env: { ...process.env, ...env }, shell: false })
    child.stdout.on('data', (d) => process.stdout.write(label(d) + '\n'))
    child.stderr.on('data', (d) => {
      process.stderr.write(label(d) + '\n')
      appendFileSync(logFile, d)
    })
    child.on('exit', (code) => {
      children.splice(children.indexOf(child), 1)
      if (stopping) return
      console.log(label(`exited (${code}); restarting`))
      setTimeout(launch, 1000)
    })
    children.push(child)
  }
  launch()
}
```

```js
/**
 * Spoken phrases through the whole chain with nothing actually done.
 * Start JARVIS first with `npm run start:dry`, then run `npm run chain`.
 */
import { existsSync, readFileSync, statSync } from 'node:fs'
import { homedir } from 'node:os'
import { join } from 'node:path'
import WebSocket from 'ws'
import { globToRegExp } from '../bridge/tiers.mjs'

const BRIDGE = process.env.JARVIS_BRIDGE ?? 'http://127.0.0.1:8787'
const ORIGIN = 'http://localhost:5173'
const AUDIT = join(homedir(), '.jarvis', 'audit.log')
const cases = JSON.parse(readFileSync(new URL('../test/fixtures/chain.json', import.meta.url), 'utf8'))

async function transcribe(file) {
  const bytes = readFileSync(new URL(`../test/fixtures/${file}`, import.meta.url))
  const res = await fetch(`${BRIDGE}/stt`, {
    method: 'POST',
    headers: { 'content-type': 'audio/wav', origin: ORIGIN },
    body: bytes,
  })
  if (!res.ok) throw new Error(`stt answered ${res.status}`)
  return (await res.json()).text ?? ''
}

function askOnce(ws, text, id) {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error('no answer within 120 s')), 120_000)
    const onMessage = (raw) => {
      const msg = JSON.parse(raw.toString())
      // Dry run never asks, but never leave a question hanging either.
      if (msg.type === 'confirm') {
        ws.send(JSON.stringify({ type: 'reply', id: msg.id, approved: false, answer: 'chain test' }))
      }
      if (msg.ask !== id) return
      if (msg.type === 'done' || msg.type === 'error') {
        clearTimeout(timer)
        ws.off('message', onMessage)
        resolve({ error: msg.type === 'error' ? msg.message : null })
      }
    }
    ws.on('message', onMessage)
    ws.send(JSON.stringify({ type: 'ask', id, text }))
  })
}

const auditSince = (offset) =>
  existsSync(AUDIT)
    ? readFileSync(AUDIT).subarray(offset).toString('utf8').split('\n').filter(Boolean).map((l) => JSON.parse(l))
    : []

const ws = new WebSocket(BRIDGE.replace(/^http/, 'ws'), { origin: ORIGIN })
await new Promise((resolve, reject) => {
  ws.once('open', resolve)
  ws.once('error', reject)
})

let failed = 0
for (const [i, c] of cases.entries()) {
  const offset = existsSync(AUDIT) ? statSync(AUDIT).size : 0
  const heard = await transcribe(c.wav)
  const { error } = await askOnce(ws, heard, `chain-${i}`)
  const called = auditSince(offset).map((e) => e.tool)
  const wants = [c.expectTool].flat().map(globToRegExp)
  const ok = !error && called.some((t) => wants.some((w) => w.test(t)))
  if (!ok) failed++
  console.log(`${ok ? 'PASS' : 'FAIL'}  ${c.wav}  heard "${heard}"  tools: ${called.join(', ') || '—'}${error ? `  error: ${error}` : ''}`)
}
ws.close()
process.exit(failed ? 1 : 0)
```
